# مولّد أوراق الأسئلة والامتحانات — ميدسكوب (Medscope Question Sheet Builder)

> أداة ويب سريعة، مجانية، وتعمل بالكامل داخل المتصفح (Client-Side 100%) بدون أي سيرفرات أو قواعد بيانات خلفية. مُصممة خصيصًا لطلاب وفريق **Medscope** في كلية الطب - جامعة الإسكندرية لتحويل بنوك الأسئلة المبعثرة ومذكرات الامتحانات إلى أوراق طباعة وتوزيع A4 احترافية في ثوانٍ معدودة.

---

## 🌟 مميزات الأداة

1. **معالجة وقراءة الملفات مباشرة في المتصفح**:
   - دعم كامل لملفات Word الحديثة (`.docx`) مع استخراج الإجابات الملونة بالأحمر تلقائيًا.
   - دعم ملفات الـ PDF مع الحفاظ على الترقيم والمواد واستخراج الإجابات.
   - دعم ملفات النصوص والقوائم (`.txt`, `.md`, `.csv`).
   - دعم قراءة الصور والملفات الممسوحة ضوئيًا عبر محرك OCR مدمج بالكامل (`Tesseract.js`).

2. **تدفق عمل مبسط للمستخدمين (3-Step Idiot-Proof Flow)**:
   - **الخطوة ١ (ضيف الأسئلة)**: منطقة سحب وإفلات ذكية للملفات مع إمكانية دمج ملف الأسئلة مع ملف الإجابات المنفصل تلقائيًا، وقسم احتياطي للصق النصوص اليدوي.
   - **الخطوة ٢ (راجع واضبط)**: بطاقة تقرير ذكية توضح عدد الأسئلة والمواد وتوزيع الإجابات (A/B/C/D)، مع لوحة المشاكل الذكية للإصلاح الفوري بضغطة زر (الأسئلة بدون إجابة، التكرارات، الكتل المتروكة).
   - **الخطوة ٣ (تخصيص الشكل ونزّل الـ PDF)**: معاينة تفاعلية حية لورقة A4 الجاهزة للطباعة مع أزرار مباشرة لطباعة ورقة الأسئلة الصافية وورقة الإجابات النموذجية.

3. **لوحة تخصيص شكل عميقة (Canva-like Customization)**:
   - **5 قوالب جاهزة (Presets)**:
     - `Soft`: تصميم مريح للعين مع ألوان دافئة وبادجات دائرية (الافتراضي).
     - `Classic`: مظهر رسمي موفر للحبر للأوراق الامتحانية التقليدية.
     - `Minimal`: تصميم أبيض وأسود بسيط بدون أي عناصر بصرية ثقيلة.
     - `Modern`: خطوط Inter عصرية وألوان حيوية متناسقة.
     - `كبير ومريح`: خطوط كبيرة (18pt) ملائمة للمطالعة السريعة على الموبايل بدون تكبير.
   - **6 بالتات لونية متناسقة** + إمكانية اختيار درجات الألوان بالتفصيل.
   - **تعديل الهوامش والأعمدة**: تقسيم الصفحة إلى 1 أو 2 أو 3 أعمدة مع خط فاصل رأسي وهوامش منفصلة (Top, Bottom, Inside, Outside).
   - **تخصيص العلامة المائية واللوجو**: لوجو ميدسكوب الرسمي الافتراضي عالي الجودة بدقة تامة وخلفية شفافة، مع إمكانية رفع لوجو مخصص (PNG / SVG / WebP / JPG) وضغطه تلقائيًا وتخزينه في `IndexedDB`، مع أزرار التحكم الثلاثة: `غيّر`، `شيل الصورة`، `رجّع لوجو ميدسكوب`.
   - **أزرار التراجع والإعادة (Undo/Redo)** للتعديلات وحفظ ستايلات مخصصة وتصديرها/استيرادها كـ JSON.

4. **طباعة A4 حقيقية خالية من العيوب**:
   - محرك تقسيم الصفحات يضمن عدم انشطار أي سؤال بين صفحتين.
   - منع بقاء عناوين المواد وحيدة أسفل الصفحة (Orphan Headings Protection).
   - إمكانية طباعة أو حفظ الـ PDF مباشرة باستخدام اختصار `Ctrl + P` أو زر التنزيل مع تفعيل `Background graphics`.

## 🔒 الخصوصية والأمان وملاءمة العمل بدون إنترنت (Offline Ready)

- **أمان وخصوصية 100%**: ملفاتك وأسئلتك لا تُرسل نهائيًا إلى أي خادم خارجي. جميع العمليات تجري بالكامل في ذاكرة متصفحك.
- **تطبيق ويب تقدمي (PWA)**: يحتوي على ملف `manifest.json` وأيقونة النسر الكوكبي لميدسكوب، مع `sw.js` (Service Worker) لتخزين كافة الأصول وإتاحة فتح الأداة والعمل عليها بدون اتصال بالإنترنت.
- **استضافة ذاتية لكافة الخطوط والمكتبات**:
  - تم تنزيل وحزم خطوط `Cairo` و `Inter` و `Carlito` محليًا بصيغة WOFF2 تحت `public/fonts/`.
  - تم تضمين `pdf.worker.mjs` ومحرك `Tesseract.js` مع ملف `eng.traineddata.gz` محليًا للعمل دون الحاجة لأي CDN خارجي.
- **رؤوس حماية متقدمة**: ملف `public/_headers` يفرض سياسة أمان صارمة (`Content-Security-Policy`).

## 💻 التشغيل المحلي والتطوير

### المتطلبات
- بيئة [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث).
- مدير الحزم `npm`.

### خطوات التثبيت والتشغيل
```bash
# 1. تثبيت الحزم البرمجية
npm install

# 2. تشغيل سيرفر التطوير المحلي
npm run dev

# 3. فتح الموقع في المتصفح على:
# http://localhost:5173/
```

### تشغيل الاختبارات
```bash
# تشغيل اختبارات الوحدة والدمج (Vitest)
npm test

# تشغيل اختبارات المتصفح الحقيقية E2E (Playwright Chromium)
npm run test:e2e
```

## 🚀 النشر والاستضافة (Deployment Guide)

المشروع عبارة عن موقع ثابت (Static Site) يمكن استضافته مجانًا على أي خدمة استضافة بدون إعدادات خادم معقدة:

### 1. الاستضافة على GitHub Pages (تلقائي)
المشروع مزود بملف جاهز لـ GitHub Actions (`.github/workflows/deploy.yml`):
1. ارفع المشروع إلى مستودع GitHub على الفرع الرئيسي (`main`).
2. ادخل على **Settings** في مستودع GitHub -> ثم **Pages**.
3. في خانة **Source** اختار **GitHub Actions**.
4. عند أي `git push` على فرع `main` سيتم بناء المشروع ونشره تلقائيًا.

### 2. الاستضافة على Netlify
- **طريقة السحب والإفلات (Drag & Drop)**:
  1. نفذ أمر البناء محليًا: `npm run build`.
  2. افتح [Netlify Drop](https://app.netlify.com/drop).
  3. اسحب مجلد `dist` المولد وأفلته في الصفحة.
- **الربط مع مستودع Git**:
  - **Build Command**: `npm run build`
  - **Publish directory**: `dist`

### 3. الاستضافة على Cloudflare Pages
1. سجل الدخول إلى Cloudflare Dashboard -> **Compute (Workers) & Pages**.
2. أنشئ تطبيقًا جديدًا من نوع **Pages** واربطه بحساب GitHub.
3. اضبط إعدادات البناء:
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. اضغط **Save and Deploy**.

### 4. ربط دومين مخصص (Custom Domain)
1. في إعدادات الاستضافة (سواء Netlify أو Cloudflare أو GitHub Pages)، أضف نطاقك المخصص (مثل `exams.medscope-alex.org`).
2. أضف سجل `CNAME` في مزود الـ DNS يشير إلى عنوان الاستضافة.

## 🛠 بنية المشروع البرمجية

```
├── public/
│   ├── fonts/                   # خطوط محصنة محليًا (Cairo, Inter, Carlito)
│   ├── pdfjs/                   # مشغل pdf.worker.mjs المحلي
│   ├── tesseract/               # مكتبة الـ OCR وبيانات اللغة الإنجليزية eng.traineddata
│   ├── _headers                 # إعدادات الحماية وسياسة CSP
│   ├── manifest.json            # مواصفات تطبيق الـ PWA
│   ├── sw.js                    # Service Worker للعمل أوفلاين
│   ├── medscope-eagle.svg       # أيقونة نسر ميدسكوب
│   └── medscope-watermark-default.png # اللوجو الرسمي الافتراضي
├── src/
│   ├── idb.js                   # مخزن IndexedDB للصور واللوجو الكبير
│   ├── imageHelper.js           # محرك ضغط ومعالجة الصور وSVG
│   ├── parser.js                # محرك استخراج الأسئلة والإجابات والأنماط
│   ├── paginate.js              # محرك تقسيم الصفحات A4/A5 ومنع انشطار الأسئلة
│   ├── paper.js                 # صانع شفرة HTML لورقة الامتحان والغلاف
│   ├── settings.schema.js       # تعريفات القوالب، البالتات، والأنماط
│   ├── settings.js              # واجهة تحكم التخصيص والأكورديون
│   ├── state.js                 # إدارة الحالة، سجل التراجع Undo/Redo، والتخزين
│   ├── stats.js                 # شريط الإحصائيات ورسم توزيع A/B/C/D
│   ├── problems.js              # لوحة المشاكل وبطاقة التقرير مع الإصلاح الفوري
│   ├── editor.js                # محرر الأسئلة التفاعلي
│   ├── export.js                # التصدير لصيغ Anki, Quizlet, JSON, Text
│   ├── import/                  # معالجات قراءة DOCX, PDF, OCR, TXT
│   └── styles/                  # ملفات التنسيق (tokens, app, paper, print, fonts)
├── tests/
│   ├── parser.test.js           # اختبارات دقة المعالج النصي
│   ├── acceptance.test.js       # اختبارات قبول العينات الرسمية
│   └── e2e-browser/             # اختبارات المتصفح الحقيقية Playwright Chromium
├── index.html                   # الهيكل الرئيسي للتطبيق
├── main.js                      # منسق التطبيق ومحرك التدفق ثلاثي المراحل
└── vite.config.js               # إعدادات Vite مع base: './'
```
